# 牌谱和电脑打法的工具

这几个脚本用来把真人打的牌局拿来复盘，迭代改进电脑的打法。只在电脑上用 Node.js 跑，网页本身不需要它们。

## 牌谱存在哪里

每打完一把，页面都会记一份牌谱，记下这些内容：

- 发的牌
- 每一手谁出了什么
- 这手是人出的、电脑出的，还是超时后系统代出的
- 结果和罚几份

牌谱存在三个地方：

- **这台手机里**：浏览器的 `localStorage`，键名是 `gz-recs`，最多存 400 把。
  - 对战版和练习版在同一个网站下，所以共用这一份。
  - 练习版菜单里的“导出牌谱”会把这里的牌谱下载成 JSON 文件。
- **联机服务器**：只有对战版会传，每把一条保留消息。
  - 服务器是 `broker-cn.emqx.io` 或 `broker.emqx.io`。
  - 主题是 `mangshi-gongzhu/v1/rec/<牌谱 id>`。
  - 在对战版页面的控制台运行 `await __gzNet.getRecs(8000)`，能把服务器上的牌谱全部取回来。
- **Claude 里打开的练习版**：存在页面数据库的 `recs` 集合里。
  - 一天一份，每份最多 100 把。

## 牌谱格式（v1）

```
{ id, app, bot, t, mode: 'sp'|'mp', room, dev, me, lvl, timer, hand, leader, first7,
  seats: [{k: 'h'|'b'|'e', n: 名字, u: 玩家 id}] ×4,
  deal: [[13 张] ×4],            // 牌 = 花色*13 + 点数；花色 0♠ 1♥ 2♦ 3♣，点数 0='2' … 12='A'
  plays: [[座位, 牌], …],         // 出牌顺序（投降时没打完的那墩也在里面）
  by: 'hbba…',                    // 每一手：h 人、b 电脑、a 超时代出；对不上时为空
  surr: 投降的座位或 null,
  res: { w: 赢的队, k: normal|tie|small|grand|surrender, sc: [四家得分], pen: 罚几份 } }
```

## 复盘

```
node tools/review.js 牌谱.json k=32 out=report.md json=detail.json
```

- 每一手人出的牌，都让高手档电脑也想一遍。
- 再用同一批随机发牌往后推演，算出“人出的这张”和“电脑会出的那张”平均差几份。

输出的报告包括：

- 每个人和电脑出得一样的比例
- 吃亏最多的几手（失误）
- 人比电脑出得好的几手（电脑该学的地方）
- 配合约定的使用情况

## 新旧电脑对打

```
node tools/duel.js n=300 new=新.html old=旧.html
```

同一副牌两队换座位各打一遍，结果包括：

- 新电脑那队赢几成
- 平均每把净赚几份
